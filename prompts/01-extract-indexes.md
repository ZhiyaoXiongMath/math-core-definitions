# 第一步提示词：提取并缓存数学书籍的 Index

## 你的任务

根据用户提供的 INPUT_DIR，读取该目录的 main.tex 参考书目，匹配书籍 PDF，只提取各书书末 Index 的内容，并保存为第二步可以直接读取的本地文本缓存。

本阶段只完成索引收集，不筛选或排序定义，不生成 core_definitions.tex。第二步才根据这些 Index 筛选核心定义与重要定义，并按重要性全局排名。

必须限制在索引相关页面。不要通读正文，不要提取整书文本，不要对整书进行 OCR。

## 输入与默认输出

- INPUT_DIR：用户提供的、含 main.tex 和数学书籍 PDF 的文件夹。
- INDEX_DIR：可选；默认 INPUT_DIR/.core-definitions-work/indexes。
- MANIFEST_PATH：可选；默认 INPUT_DIR/.core-definitions-work/index-manifest.json。

从本次调用获取真实路径，不假定学科、书籍数量或固定书名。若作为第二步之前的第一阶段执行，完成后把这些路径交给第二阶段。

## A. 核对书目与文件

1. 读取 main.tex，提取其中的书名、作者、引用键或 MR 编号。
2. 根据 MR 编号、作者和书名匹配本目录中的书籍 PDF。文件名不足以确认时，仅查看封面或版权页。
3. main.tex 仅用于确定书目范围，不能作为索引或定义内容的来源。
4. 不把生成的 core_definitions.pdf、书目预览 PDF 或不属于书目的文件当作数学书籍输入。
5. 翻译版、不同版次、部分资料或多个候选文件应如实记录。不能确认的匹配不要强行认定。
6. 缺少 PDF 时记录该书状态，继续处理其他书籍；不要自动联网补书，也不要读取其他分类目录。
7. 已有缓存时核对源 PDF 的路径、大小及修改时间，必要时核对哈希。确认来源未变化的有效缓存可以复用，避免重复提取。

## B. 定位每本书的 Index

按低读取量的顺序定位：

1. 先检查 PDF 书签、目录信息或少量目录页，查找 Index、Subject Index、General Index、Index of Terms、名词索引、主题索引等。
2. 没有定位信息时，从书末少量页面开始查看，按需向前扩大范围，直到找到索引的开始和结束。
3. 分清书末 Index 与书前 Contents/Table of Contents。目录只辅助定位，不能用章节标题代替 Index。
4. 优先提取数学主题索引。纯作者索引不必提取；符号索引只有在包含可辨识的概念名称时才作为补充，并记录其类型。
5. 同一本书存在多个相关数学索引时，分别识别并覆盖其相关页面。
6. 使用 PDF 实际页序记录范围，采用从 1 开始的页码。印刷页码可另行保留，不要混淆两者。

允许读取文件元数据、定位所需的少量页面以及实际索引页面。不要先把整本 PDF 转为文本，再从整书文本中搜索 Index。

## C. 完整提取索引并保存

1. 有可靠文本层时，只对已定位的索引页提取文本。
2. 扫描页或文本层损坏时，只渲染和 OCR 索引页。不要启动整本 OCR。
3. 检查多栏顺序、断词、连字符、缩进、子条目、see/see also 交叉引用和数学符号，避免混栏及漏行。
4. 保留索引原有的页码、上级条目、子条目和交叉引用。这些信息用于后续理解名称关系，不应在本阶段删掉。
5. 对明确的 OCR 错字可依据对应索引页图像纠正；不根据数学常识补造原索引中不存在的条目。
6. 每本书保存一个或多个 UTF-8 文本文件。优先以 MR 编号或引用键命名；没有编号时使用稳定、可辨识的书名。
7. 文本文件注明书名、源 PDF、实际索引页范围，并用简短页分隔标记保留对应关系。
8. 需要视觉核对的索引页图像可以保存在该书缓存子目录中，供第二阶段检查模糊术语。
9. 原始索引中的辅助概念也要保留，不在第一步进行重要性筛选。
10. 索引较长时分批处理，直到可读取的索引页面均已覆盖，不因一次工具输出截断而漏掉后续内容。

## D. 写入索引处理清单

在 MANIFEST_PATH 保存 JSON，至少记录每本书的：

- 引用键或 MR 编号、书名、作者；
- 源 PDF 的绝对路径、文件大小、修改时间；
- PDF 总页数；
- 实际提取的索引页序及索引类型；
- 文本缓存文件的路径；
- 提取方式：文本层、索引页 OCR，或二者结合；
- 状态：complete、partial、pdf_missing、index_not_found、unreadable；
- 简短的客观缺失或识别问题。

不能定位索引时标记 index_not_found，不要据此断言整本书没有索引。部分页面无法读取时标记 partial，不能记为完整。

## 本阶段完成条件

- 本目录书目中的每本书均已匹配 PDF，或记录无法匹配的情况。
- 所有已经定位且可读取的相关 Index 均有完整文本缓存。
- 索引页范围和提取状态清楚，第二步能够直接找到文本，不必重新阅读 PDF。
- 未修改 main.tex、原始 PDF 或其他分类目录。
- 若没有任何可用索引，明确报告原因，不伪造缓存。

作为两阶段工作流的一部分时，到此再进入第二步。
单独调用本提示词时，只完成索引提取和缓存，并简短告知缓存位置及缺失情况；不要自行开始生成核心定义清单。
