# 数学定义名称提取与重要性排名：通用两阶段工作流

版本：0.2.0。

## 目标

输入一个或多个文件夹，每个文件夹含 main.tex 参考书目和数学书籍 PDF，且已由用户分好数学大类。每个目录独立生成 core_definitions.tex。

清单仍只收录核心定义和重要定义的英文名称，但以重要性全局排名：核心定义在前、重要定义在后，各层次内从重要到次重要，用连续编号表示名次。排名用于后续定理评价中的概念重要性参考，本流程不直接计算定理质量分数。

默认不分 section；确有必要时最多 3 个，分段不能改变全局排名，编号不能重置。只输出名称和排名，不解释定义或给出数值评分。

## 两步必须依次执行

1. 第一步：完整提取并缓存本目录各书可取得的书末 Index。
2. 第二步：只根据这些 Index 筛选、整合、全局排名并生成 core_definitions.tex。

不通读正文、不提取整书文本、不对整书 OCR。目录、书签及少量定位页只用于定位索引。

## 输入参数

- INPUT_DIR，或 INPUT_DIRS：一个或多个含 main.tex 和书籍 PDF 的文件夹地址。
- CATEGORY_LABEL：可选，仅用于理解当前数学大类；通常参考文件夹名称和书目即可，不要求用户额外提供。
- MODE：直接执行，或为每个目录派发一个新对话。仅用户明确要求新对话时使用后者。
- MODEL、THINKING：可选；创建新对话时使用用户明确指定的模型及推理档位。

输出文件名为 core_definitions.tex，文档标题按固定模板使用 Core Mathematical Definitions。本文件不写死学科、源资料路径或分类数量。

## 同目录资源

以本文件所在位置为 PROMPT_DIR：

- 01-extract-indexes.md：第一步提示词，可独立调用。
- 02-index-to-core-definitions.md：第二步提示词，可独立调用，内含完整模板和排名标准。
- assets/core_definitions.tex：固定模板，默认无 section，使用连续排名列表。
- scripts/validate_output.py：格式检查器，只检查模板、0–3 个 section 与连续编号结构，不判断重要性。

本提示词包可以独立于已安装 skill 使用。第二步 Markdown 也可单独提供给执行者，按其内嵌模板完成任务。

## 直接执行

对每个输入目录：

1. 读取并执行第一步提示词，复用来源未变化的可靠缓存。
2. 本目录可取得的 Index 处理完毕后，直接执行第二步，不需要再确认。
3. 先筛选、去重、规范术语，再确定整个目录的全局重要性排名，最后决定是否需要至多 3 个 section。
4. 校验、编译并交付该目录的 core_definitions.tex。

不同目录独立排名和去重，同一概念可以出现在不同类别中。跨类别的名次不能直接当作相同尺度的分数。

## 用户明确要求派发新对话时

主对话发现并使用 create_thread，为每个目录创建一个独立的本地聊天；不以后台子代理代替用户要求的新聊天。设置用户指定的 MODEL、THINKING，不擅自替换。普通本地资料任务使用 projectless，不创建工作树或云任务。

初始消息应使用已解析的绝对路径：

~~~text
你负责一个已分类资料文件夹的定义名称提取与重要性排名。

输入目录：{{INPUT_DIR}}
数学大类：{{CATEGORY_LABEL}}
第一步提示词：{{PROMPT_DIR}}/01-extract-indexes.md
第二步提示词：{{PROMPT_DIR}}/02-index-to-core-definitions.md
最终输出：{{INPUT_DIR}}/core_definitions.tex

先完成各书 Index 提取和缓存，再根据 Index 筛选、整合并全局排名。
核心定义在前，重要定义在后，各层次内按重要性递减排列。
默认不分 section；确有必要时最多 3 个，分段不能改变排名，
所有条目的编号从 1 开始连续递增，跨 section 不重置。

本任务用于提供概念重要性参考，不直接给具体定理打分。
只列英文名称与名次，不通读正文、不解释定义。
依次执行两个阶段，不需要中途确认。只处理本目录，不创建更多聊天。
完成后交付本目录的 core_definitions.tex，并简短说明实际材料缺口。
~~~

创建后核实任务启动并返回各新对话入口，跟进至交付。主对话不同时编辑执行者的输出文件，也不重复读取全部索引。

## 文件约定

- 保留原 main.tex 和 PDF。
- 缓存仍使用 INPUT_DIR/.core-definitions-work，不因升级排名规则重新提取可靠 Index。
- 每个目录最终只交付 core_definitions.tex；不额外交付 PDF、定义解释或审查报告。
- 无可用索引时不凭常识编造清单；索引不完整或编译验证受限时在聊天中简短说明。
- 不声称已经通读正文。格式检查通过也不等于重要性排序已自动获得验证。
