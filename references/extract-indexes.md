# 第一步：核对、复用与读取 Index

完整规范见 [core-definitions-rules.txt](core-definitions-rules.txt) 的 PURPOSE AND INPUT 与 A1–A6。本文件补充执行细节，不另设输入门槛。

## 盘点实际证据

以用户标签或目录确定学科，用 main.tex 书目、其他清单或 manifest 匹配书籍；没有清单时盘点实际输入。以引用键、MR 编号、书名和作者保持书籍身份，不因书名与学科不同而排除已列入的书。

区分源书籍、索引材料与生成清单/编译产物。只有 Index 的输入是正常模式，不要求补交 PDF 或 main.tex。身份不明时使用已有清单及实际内容核对，有 PDF 才查看必要的封面或版权页。记录翻译、替代版次、部分材料及未确定匹配，不将其一律改为已通过。

## 复用与修复

常规布局为 INPUT_DIR/.core-definitions-work/indexes，以及其父目录的 index-manifest.json。可复用其他清晰布局，不为规范化路径重提取有效材料。把转移 manifest 的历史路径映射到实际文件，保留书籍身份；旧绝对路径不可达本身不使现存缓存失效，新便携记录使用相对路径。

检查文件身份、可读性、声明页覆盖、续页、多栏、子条目和交叉引用。有缓存哈希时比对；匹配只证明所供字节一致，不能证明 OCR 正确、历史审查正确或缺席原件的索引完整。大小、时间戳和旧 complete 标志也不能代替内容核对。

有原 PDF 才核对源身份并修复受影响的 Index 部分。缺席原件时，区分本次观察与继承声明，记录哪些检查不能重复；继续使用可读材料，不强制恢复全部缺页。不要把“未读正文”记为失败。

逐书记录以下证据状态（可映射已有清单的等义状态）：

- complete-as-supplied：所供材料可读，所声明的供给范围已交代，不代表验证过缺席原书的完整 Index。
- partial：有可用内容，同时有已知缺页、续页、列或识别缺口。
- unavailable：当前没有可用 Index 材料；无法定位不等于断言原书没有 Index。
- unresolved：材料身份、范围或可用性尚不能确定，保留简短事实说明。

复用适当格式，不强制数据库或清单 schema。记录书籍身份、现有源/缓存文件、索引类型与位置、已知页覆盖、适用的提取方式、状态及实际问题。只记录确实已知的原 PDF 元数据；原件缺席时不得要求或编造哈希、大小、总页数。

## 有 PDF 时定位与提取

1. 先用书签、目录信息或少量目录页查 Index、Subject Index、General Index、Index of Terms、名词索引等；必要时从末尾少量页按需向前扩大定位，不能先提取整书文本再搜索。
2. 书前 Contents/Table of Contents 只能帮助定位，不能替代 Index。纯作者索引不提供候选；所有可用主题索引和含概念名称的符号索引均须覆盖，裸符号不是候选名。
3. 区分从 1 开始的 PDF 实际页序与印刷页码。只提取已定位的 Index 页，必要时只渲染和 OCR 缺损索引页；不读正文，不沿页码访问正文，不保存整书渲染图像。
4. 保留原页码、父子层级、缩进、断词和 see/see also，检查多栏顺序与续页。依据实际上下文或可用图像纠正 OCR，不用数学常识补造条目。

## 读全、保留候选后再最终筛选

读完每本书全部可用相关 Index。长索引可分批，不因工具截断、熟悉程度或抽样而漏读；每批保留候选名与具体 Index 位置，全部批次合并后再做最终准入和全局排名。一个 Index 的多份转录是替代证据，不能重复计票。

候选依据仅限真实条目、父子结构及交叉引用，不能用旧生成清单补候选或继承排序。数学知识只辅助术语、同义与重要性判断。现有索引上下文或图像仍不能消解的名称，排除该候选并保留简短事实性疑点。

每个输入均有处理记录即可进入筛选，不要求原件齐全或所有缺口补齐。若该学科无任何可用 Index，报告缺口并继续其他学科，不凭空生成清单。
