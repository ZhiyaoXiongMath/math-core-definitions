# 第二步：筛选、排名与输出

完整规范见 [core-definitions-rules.txt](core-definitions-rules.txt) 的 B1–F4。先读完全部可用 Index，再完成准入、命名去重及最终排序。分批结果须合并，不能直接拼接各书或各主题的局部排名。

## 准入与名称复核

- 核心概念组织学科主要理论；重要概念在理论、重大结果或可复用方法中具有独立实质作用，仅为局部论证所需不足以入选。
- 对象、结构、条件、不变量、构造、分解、算子、方程和可复用方法均可合格。排除临时记号、证明局部标签、孤立辅助词、一般词语、裸人名、书名及定理或猜想标题。按角色判断：独立索引的概念或可复用工具即便通常表述为定理也可合格；不能缩短或改写命题标题使其冒充概念，定理、猜想或公式本身不能为另一概念提供依据。不因人名而排除实质概念。
- 每个特例和相关构造独立达到同一阈值；相关但不同的概念不必合并，也不自动全部纳入。一般背景不自动核心，专业概念不自动次要；不得设置数量、篇幅、书籍或主题配额。
- 排序前重查主要索引结构和方法有无遗漏，跨主题比较边缘项的一致性。不为填预期空缺增加无依据词，也不为覆盖所有变体扩表。只给真正未决或影响重大的决定留简短事实记录，无须逐项论证或穷尽拒绝清单。
- 由父子条目和交叉引用恢复完整英文名，翻译非英文名但不打印双语。保留必要对象、范畴和假设，不凭学科猜加更强限定。宽泛不等于歧义；确实无法区分意义时按 A6 排除，不查正文猜义。
- 仅合并真正同义项和拼写变体并保留已知来源链接；不混并相关构造、一般/特殊情况、不同范畴或只在额外假设下等价的概念，也不把索引词扩展成另一结构。不确定同义时不强合并；同概念可出现在不同学科清单。
- 一项一个概念，不捆绑独立名称，不附同义词目录、定义或解释。概念名的普通数学记号可保留，如 $L^2$ cohomology、$\mathrm{Spin}^c$ structure；性质公式不允许。

## 全局重要性与来源记录

先完成准入、命名和去重，所有核心项在所有重要项之前。各层优先比较对用户学科主要理论与重大结果的结构性中心地位、组织或连接重要结果的范围，以及在实质方法中的关键作用。学科范围与来源覆盖限制分开记录。

跨书使用可辅助判断，但频率、引用页数、提及书数和重复版次都不是权重。一般性、抽象、难度、名气、名称长度和基础性均无自动优先权。重要性高于教学、前置依赖、书籍、字母和主题顺序；仅当同层内无可靠重要性区别时按规范英文名字母顺序打破并列，不编数值分数，也不把并列排序说成实质差距。

跨主题和相隔较远的部分复核，特别留意后部主要概念及长串同主题项；同时查前列、可比相邻项、一般/特殊对及层次边界。连续主题段只触发检查，不自动判错，不机械交替主题。

必须保留简洁内部来源对应记录：最终名次、规范名、内部层次，以及至少一个可识别 Index 条目的书籍标识、缓存文件、可用位置、必要父条目；已知同义合并的来源链接也保留。可用相对缓存路径配页标记、行号或可定位条目上下文，不规定数据库或文件格式。记录是事实性溯源，不是私密推理、逐项评价文章或额外读者报告；交付前须与最终 TeX 的实际条目、名次一致。

## 生成与交付

1. 使用 [template.tex](../assets/template.tex) 生成完整候选。最终名称为 CLASS_core_definitions.tex，CLASS 取学科目录完整名称，保留大小写与空格；带标签附件使用同标签工作目录。文档标题仍固定为 Core Mathematical Definitions。
2. 模板已内嵌 [preamble.tex](../assets/preamble.tex)，不能再次加载。保持类、宏包（包括 cmap）、页边距、标题、author/date、列表设置及文档框架。比较 \begin{document} 之前的块时仅规范换行并忽略末尾空白行，不能忽略其他空格或内容差异。生成期间源四件套不变，输出完全独立。
3. 默认无 section，只有一个 \begin{enumerate}[series=definitions]。允许 1–3 个宽泛英文 section 仅切分已经排好的自然连续块，不为聚主题移动条目；主题交错无法自然分段时保持 0 个。每节后恰好一个列表，首列表用 [series=definitions]，后续均用 [resume=definitions]。不混合有节与无节列表，不用手工 item 标签或设置/重置计数器。
4. 一项一源码行，允许自然排版换行。删除 Concept name 占位项。最终只能有固定标题、允许的节标题、从 1 开始的自动阿拉伯名次及英文概念名；禁止定义、解释、引用、来源页、层次、评分、备注或报告（含注释），禁止 subsection、嵌套列表、表格、装饰、自定义宏、外部输入或新宏包。重音与必要数学记号使用固定导言支持的普通 LaTeX。
5. 复核来源支持、准入一致性、命名、同义处理和全局排序，再对照实际条目核对来源记录。运行 python <SKILL_DIR>/scripts/validate_output.py <CANDIDATE_TEX>；格式通过不能证明数学质量、来源完整或名称语义合格。
6. 用标准编译器（例如 pdfLaTeX）编译实际完整候选，明确指定目标。可在工作缓存临时目录以最终目标文件名编译，不能以原 main.tex、导言片段或旧输出代替。使用 compile_latex_document 时显式指定候选所在目录、实际文件名和输出路径，不预设工具存在。查看页面截断、缺字与编号，修正真实错误，区分成功、未执行和失败；编译器缺席不等于编译失败。
7. 目标已存在时，覆盖前在工作缓存创建唯一、不覆盖既有备份的副本，并用字节比对或哈希核验未变；先完成候选检查，再原样复制候选替换。保存必要检查事实，不将检查失败的候选标为已接受。
8. 每学科交付一个目标 TeX 文件入口。PDF 仅在用户要求时交付；工作索引和内部来源记录保留供复用，不加入读者清单。聊天中简要披露实际来源缺口、未决材料、版次差异及未完成或失败检查。部分材料可支持有限范围结果，但不能称完整；不得声称做过缺席原 PDF 核验、正文阅读或未执行的端到端测试。
