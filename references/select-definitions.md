# 第二步：根据 Index 生成核心定义名称

## 输入范围

读取当前 INPUT_DIR 的索引清单与所有可用索引文本。可以分批读取，避免截断。无需重读 PDF；名称模糊时可查看已缓存的对应索引页图像，不到正文逐条核验定义。

只使用有索引依据的概念。可运用数学知识判断重要性、辨别同义词和组织主题，不凭常识扩充索引中没有的概念。对条目、子条目及 see/see also 的关系，先恢复完整名称再筛选。

## 筛选

保留两类名称：

- 核心定义：构成主要理论基础的重要研究对象、数学结构或关键概念。
- 重要定义：理解核心理论、主要定理或关键数学方法所必需的概念。

排除临时记号、局部技术标签、零散辅助概念、一般性词语、裸人名、书名和定理名称。重要理论工具不能仅因不是最终研究对象就被排除。

不根据引用页码数量、出现频率或名称复杂度机械判断重要性。不设置数量配额，不凑数。书目范围由输入材料决定，不因书籍与目录名称不完全一致而排除。

## 整合

- 仅在当前目录内部去重，不跨输入目录删除重复概念。
- 合并数学含义相同的同义名称，使用标准英文术语。非英文索引应转为规范英文名称，不输出双语对照。
- 上级条目和子条目可构成一个完整术语，不直接把缩进碎片当作独立名称。
- 名称相近、互为特例或关联构造的概念不能据此合并。条件、对象或范畴不同的名称保留必要限定；索引不足以确认等同时不强行合并。
- 按数学主题组织，不按书籍、章节或索引字母顺序机械排列。主题内尽量从基础对象到相关结构。
- 可在工作缓存保留“最终名称—来源索引条目”的简短对应关系，不将其写入输出 TeX。

## 输出内容

最终文档只含固定标题、英文主题标题和数学概念的英文名称。不得包含定义正文、含义解释、重要性理由、等级、页码、引用、注释、摘要、引言、结论或审查报告，也不把这些内容隐藏在 TeX 注释中。

每个概念单独使用一个 item，源文件中每项一行，PDF 中允许自然换行。必要的名称记号可以保留，例如 $L^2$ cohomology、$\mathrm{Spin}^c$ structure、$C^k$ manifold；不输出定义公式或性质公式。

## 强制模板格式

读取本技能 assets/core_definitions.tex，并复制为 INPUT_DIR/core_definitions.tex 后填写实际内容。模板中的 Topic Title 和 Concept name 是格式示意，不能留在最终结果中。

只允许变动主题与条目区域：

- 使用 section 表示主题，标题为简短的标准英文数学主题名称。
- 每个 section 紧跟一个 itemize，包含一个或多个 item。
- 一个 item 只写一个数学概念名称。
- 可以增加或减少完整的 section 与其 itemize，不能增加 subsection、嵌套列表、表格、正文段落、页眉或装饰。
- 导言区、宏包、页面设置、固定文档标题、author/date、maketitle 和 document 框架必须与模板一致，不能自行添加、删除或改写。
- 不添加注释、引用命令、外部输入或自定义宏。
- 输出独立完整，不依赖章节文件、图片或书目文件。

模板是初版规范。不得因为个人排版偏好改动；后续由用户明确授权更新技能模板。

## 检查与交付

先对照索引检查遗漏、辅助词误收录、OCR 拼写、同义合并和主题分类。然后运行本技能 scripts/validate_output.py 检查结构，修正后再验证。

格式检查只验证模板及条目结构，不能替代数学筛选判断。通过后还应使用可用编译工具检查 INPUT_DIR/core_definitions.tex。内置编译时明确选中 core_definitions.tex，不能沿用原书目 main.tex。

只交付最终 core_definitions.tex 文件入口。索引不完整或无法验证编译时，在聊天中简短说明实际情况，不在 TeX 中加入说明。没有可用索引时不生成推测清单；不能声称已经阅读全部正文。
